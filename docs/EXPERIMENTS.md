# Final Experiment Files

This folder keeps only the final experiment code and artifacts used for the
paper tables and figures.

- `chunking_ablation/`: final chunking strategy runs, metrics, summaries, and
  chunk metadata.
- `retrieval_ablation/`: final retrieval strategy runs, metrics, and summaries.
- `shared/`: shared chunkers, corpus loading, index building, retrieval, and
  evaluation helpers.
- `final_paper_analysis.json`: final aggregate analysis used to check paper
  numbers.
- `FINAL_PAPER_ANALYSIS.md`: readable summary of the final analysis.
