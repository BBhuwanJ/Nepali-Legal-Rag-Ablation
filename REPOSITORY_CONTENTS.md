# Repository Contents

This is the final public export for the Nepali legal RAG ablation study.

Keep this folder focused. Do not add paper submission files, API keys, local
virtual environments, temporary render outputs, pilot experiments, or tuning
candidate folders.

Included:

- `data/`: final corpus, benchmark, and review records.
- `src/`: final evaluation and experiment scripts.
- `results/`: final metrics, summaries, populated outputs, and index metadata.
- `figures/`: final charts used in the manuscript.
- `docs/`: short benchmark and experiment notes.
- `requirements.txt`: Python dependencies.
